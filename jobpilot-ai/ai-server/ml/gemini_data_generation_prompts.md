# LoRA 재학습용 질문 데이터 보강 - Gemini에 직접 붙여넣을 프롬프트 모음

팀 공용 API 키(토큰) 안 쓰고, 본인 Gemini 앱/웹 채팅에 직접 붙여넣어서 쓰는 용도.
아래 프롬프트를 하나씩 순서대로 붙여넣고, 나온 결과를 그대로 복사해서
`ml/interview_qa_pairs.jsonl` 맨 끝에 이어 붙이면 된다(줄 하나에 JSON 객체 하나,
기존 5039줄과 같은 포맷).

각 라운드 끝나고 결과 형식이 이상하면("설명 붙임", "번호 매김" 등) "다른 말 없이 jsonl
줄만 출력해줘"라고 한 번 더 요청하면 됨.

## 라운드 1 - 자기소개/지원동기, 강점·약점, 협업·갈등 해결, 문제해결 경험

```
너는 한국 채용면접 질문 데이터를 만드는 중이야. 아래 조건을 지켜서 면접 질문 40개를 만들어줘.

- 대상: ICT 개발자 신입 채용면접
- 카테고리별로 정확히 10개씩: (1) 자기소개/지원동기 10개, (2) 강점·약점 10개,
  (3) 협업·갈등 해결 경험 10개, (4) 문제해결 경험 10개
- 문체: 실제 면접관이 존댓말로 묻는 자연스러운 한국어. 문장 끝은 "~습니까/까요/나요/
  주세요/부탁드립니다"처럼 격식 있는 의문형이나 요청형으로 끝나야 함
- 지원자를 가리킬 땐 반드시 "지원자님" 또는 "지원자분"만 써라 - "면접자" 같은 다른
  호칭은 절대 쓰지 마라
- 같은 카테고리 안에서도 서로 겹치지 않게, 표현과 소재를 다양하게 만들어라
- 출력은 아래 JSON Lines 형식으로만, 설명이나 번호, 마크다운 없이 한 줄에 하나씩만:
{"job": "ICT 개발자(신입)", "context": "", "question": "여기에 질문 텍스트"}
```

## jsonl에 합친 뒤 할 일

1. 합친 파일에서 완전 중복 줄 제거(간단히 `sort -u` 등으로도 됨)
2. `ml/debug_question_diversity.py`로 재학습 전 기존 모델 기준 다양성 한 번 더
   확인해두면, 재학습 후 결과랑 비교하기 편함
3. Colab 노트북(`mock_interview_question_generator.ipynb`)에서 이 파일 다시 업로드해서
   재학습 → 어댑터 다운로드 → `question_generator_lora`에 교체(전에 하던 방식 그대로)
