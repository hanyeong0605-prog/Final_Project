## 해석과 한계

- 44개 다중 라벨 문제이므로 Micro-F1을 단순 정확도 56.9%로 표현하지 않는다.
- 전체 감정 라벨 집합의 완전 일치율은 0.22%다. 기준 모델이 여러 세부 감정을
  정확히 모두 맞히는 수준은 아니므로 자동 판정이나 제재에 사용하지 않는다.
- 죄책감 F1 0.1186, 패배/자기혐오 0.1509 등 약한 라벨이 있다.
- 위 결과는 공개 TSV에 제공된 라벨을 그대로 사용한 결과다. 논문과의 직접 성능
  비교는 원본 평가자 라벨 합성 기준과 평가 방법까지 일치하는지 확인한 후에만 한다.
- 회사 평가의 사실 여부, 욕설/혐오 여부, 작성자의 심리 상태를 판단하는 모델이 아니다.
- 직장 도메인과 홈페이지 피드백에 대한 사람 검수 평가가 아직 없어 서비스 정확도를 보장하지 않는다.
- 표시용 극성 점수는 별도 규칙에 따른 독립적인 값이다. 합이 1인 확률이나
  긍정 리뷰 비율이 아니며, 그대로 백분율 차트나 기업 순위에 사용하면 안 된다.
- 긍정/부정/중립 매핑은 가설적 표시 정책이다. UI에는 참고용 경향으로만 노출하며,
  가상 시연 회사 TOP 10의 보조 신호로만 사용한다. 실재 기업 순위, 자동 제재,
  사실 판정에는 사용하지 않는다.
- 학습 모델은 원문 행을 저장하지 않지만 TF-IDF 어휘에는 학습된 문자 조각이 포함된다.
- Transformer 학습 및 성능 비교와 직장·서비스 도메인 사람 검수 평가는 후속 과제다.
