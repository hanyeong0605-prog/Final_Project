# 직장·채용 감정 후보 데이터 카드

## 목적

KOTE에서 부족한 직장 문맥을 점검하기 위한 프로젝트 자체 창작 데이터다. 업무강도,
보상, 문화, 경영진, 성장, 복지, 근무제도 문장을 `POSITIVE`, `NEUTRAL`,
`NEGATIVE`, `MIXED`로 구분한다.

## 현재 상태

- 12개 의미 그룹 × 5개 상황 문맥 × 4개 극성 = 240문장
- 프로젝트에서 직접 작성한 합성 문장
- 실제 기업, 실제 인물, 외부 리뷰를 사용하지 않음
- 모든 행의 `source_type`은 `SYNTHETIC_CURATED`
- 모든 초기 행의 `review_status`는 `UNVERIFIED`

이 데이터는 라벨링 후보이며 아직 사람 검수 정답 데이터가 아니다. 현재 모델의 화면
동작 확인과 검수 작업 준비에는 사용할 수 있지만, 사람 검수 전에는 최종 성능 평가나
상용 정확도 주장에 사용하지 않는다.

## 사람 검수 절차

1. 문장만 보고 전체 극성과 평가 항목을 독립적으로 판단한다.
2. 최초 라벨과 다르면 수정하고 변경 이유를 남긴다.
3. 완곡어법, 부정어 반전, 긍정·부정 혼합 문장을 우선적으로 재검토한다.
4. 검수가 끝난 행만 `review_status=VERIFIED`로 변경한다.
5. 같은 `template_group`의 문장은 동일 split에 배치해 문장 틀 누출을 막는다.
6. 검증 완료 전에는 final evaluation 명령이 실패하도록 검사한다.

## 한계

문장 형식이 실제 장문 리뷰보다 짧고 정돈돼 있으며, 작성자가 의도한 라벨을 정답으로
간주하기 쉽다. 따라서 최소 2인의 독립 검수와 불일치 조정이 필요하다. 실제 서비스
리뷰를 재사용할 때는 별도의 동의, 익명화, 보존 정책이 선행돼야 한다.
