# DART 기업 재무 분석 설계

## 목표

전체 채용공고에서 공고 상세로 진입했을 때, 별도 메뉴나 페이지 이동 없이 해당 공고 회사의 공시 재무정보와 ML 기반 전망을 제공한다. 사용자는 공고의 회사명, 공시 재무 추이, 채용 확장 신호를 한 화면에서 확인한다.

재무 분석은 공고 상세의 기존 헤더 바로 아래가 아니라 공고 이미지 다음, 기존 공고 상세 이전에 배치한다. 헤더에는 기존 outline button 스타일을 재사용한 `기업 재무 분석` 앵커 버튼을 두고, 클릭하면 섹션으로 부드럽게 이동한다.

## 범위와 원칙

- 분석 대상은 원티드 회사 중 DART 법인과 고신뢰 매칭되고, 최소 3개 사업연도의 재무 데이터가 있는 회사다.
- 일치하지 않는 회사에는 재무 데이터나 예측 점수를 추정해 채우지 않는다. 채용 확장성만 표시하고 미매칭 사유를 설명한다.
- 모든 숫자는 법인 고유번호, 사업연도, 보고서 구분, 연결/별도 기준, DART 접수번호로 추적 가능해야 한다.
- 미래를 단정하지 않는다. UI 문구는 `다음 사업연도 성장 가능성`과 확률·신뢰도로 표현한다.
- 기존 React 화면의 색상, 폰트, 카드 radius, outline button, 아이콘 체계를 사용한다. 별도 대시보드·구식 표 기반 UI는 만들지 않는다.

## DART 데이터 확보

1. `corpCode.xml`을 주기적으로 내려받아 DART 공시 대상 법인 마스터를 저장한다.
2. 원티드의 `company_name`, `company_url`, `source_company_id`와 법인 마스터를 연결한다.
3. 확정된 `corp_code`로 사업보고서(`reprt_code=11011`)의 재무제표를 조회한다.
4. 전체 재무제표에서 연결 재무제표를 우선 사용하고, 연결 값이 없을 때만 별도 재무제표를 사용한다. 한 기업의 시계열에서는 기준을 섞지 않는다.
5. 정정 보고서가 존재하면 최신 정정본을 사용하고 원 접수번호와 최종 접수번호를 남긴다.

핵심 원시 계정은 매출액, 영업이익, 당기순이익, 자산총계, 부채총계, 자본총계, 영업활동 현금흐름, 현금및현금성자산이다. 화면 지표는 원시 계정에서 계산한다.

- 매출 성장률: `(당기 매출 - 전기 매출) / 전기 매출`
- 영업이익률: `영업이익 / 매출`
- 부채비율: `부채총계 / 자본총계 × 100`
- 영업현금흐름 상태: 당기 금액과 전기 대비 변화

## 회사 매칭과 품질 관리

법인 매칭은 다음 순서로 한다.

1. 회사명 정규화 후 정확 일치: `주식회사`, `(주)`, 공백, 특수문자, 대소문자를 제거한다.
2. 저장된 별칭과 원티드 `source_company_id`/회사 URL을 이용한 재사용 매칭.
3. 유사도 후보 생성. 이 단계만으로 자동 확정하지 않는다.
4. 운영자 검증 후 별칭-법인 매핑을 저장한다.

매칭 레코드는 `CONFIRMED`, `CANDIDATE`, `UNMATCHED`, `REJECTED` 상태와 신뢰도, 매칭 방식, 검증 시간을 갖는다. `CONFIRMED`만 재무 수집과 예측에 쓴다.

첫 운영 작업은 원티드 고유 회사별로 다음 지표를 산출하는 매칭 품질 리포트다.

- 고신뢰 DART 매칭 기업 수와 공고 비중
- 3개년 재무제표 확보 기업 수와 공고 비중
- 무작위 표본 수동검수 매칭 정확도
- 업종·회사 규모별 매칭 편향

## 데이터 모델

기존 `job_postings`는 유지한다. 아래 테이블을 추가한다.

- `dart_corporations`: `corp_code`, 정식명칭, 종목코드, 법인구분, 원본 변경일
- `company_dart_matches`: 원티드 source company 식별자/정규 회사명, `corp_code`, 상태, 신뢰도, 방식, 검증 메타데이터
- `company_financial_years`: `corp_code`, 사업연도, 보고서 코드, 연결/별도 기준, 접수번호, 원시 계정, 수집 시각
- `company_financial_metrics`: 연도별 계산 지표와 결측 상태
- `company_hiring_monthly_metrics`: 회사별 월간 활성 공고 수, 개발직 비중, 직군·기술스택 집계
- `company_growth_predictions`: 모델 버전, 기준연도, 확률, 등급, 신뢰도, 입력 피처 스냅샷, 생성시각

## ML 학습과 예측

### 학습 데이터

학습 데이터는 우리 원티드 기업만으로 만들지 않는다. DART에서 재무 시계열을 확보한 다수 공시기업의 `기업-기준연도` 행으로 구성한다.

각 행은 그 기준연도 시점에 알 수 있던 최근 3개년 재무 피처와, 다음 사업연도의 실제 재무 결과를 결합한다.

```text
입력: 2021년까지의 A기업 매출·이익·부채·현금흐름 추이
정답: 2022년 A기업의 실제 매출 성장률·수익성 개선 여부·현금흐름 상태
```

학습 라벨은 다음 세 가지로 분리한다.

- 다음 사업연도 매출 성장률(회귀)
- 다음 사업연도 수익성 개선 여부(분류)
- 다음 사업연도 재무 안정성 악화 위험(분류)

UI의 `긍정적/주의/부정적` 전망은 이 세 결과를 조합한 표현이며, 원시 모델 라벨이 아니다. 모델은 업종, 규모, 상장/기타법인 구분을 피처 또는 층화 기준으로 사용해 대기업 편향을 줄인다.

### 검증

- 무작위 행 분할을 금지하고, 기준연도 기준 시간 분할을 사용한다.
- 특정 기준연도의 예측은 그 이후 공시를 피처에 포함하지 않는다.
- 운영 전 별도 테스트 기간의 매출 성장 MAE, 수익성 개선 분류 성능, 확률 보정 결과를 모델 레지스트리에 저장한다.
- 성능 기준을 통과하지 못했거나 입력 데이터가 3개년 미만이면 예측 카드를 표시하지 않는다.

원티드 채용 데이터는 수집 이력이 축적되기 전까지 모델 피처가 아닌 화면의 보조 근거다. 월별 데이터가 충분히 쌓인 뒤에만 별도 재검증을 거쳐 모델 피처로 추가한다.

## API와 동기화

- 관리/배치: 법인 마스터 동기화, 매칭 후보 생성, 연도별 재무 수집, 학습 데이터 생성, 모델 학습·평가.
- 공고 상세 조회: `jobPostingId` 기준으로 확정 매칭, 최신 재무 시계열, 계산 지표, 예측 결과, 출처를 한 번에 반환한다.
- 상세 조회 요청에서 DART를 실시간 호출하지 않는다. 수집·계산·예측 결과를 저장하고, 실패 시 캐시된 마지막 정상 결과를 사용한다.
- DART API 키는 `DART_API_KEY` 환경변수로만 읽으며 API 응답, 애플리케이션 로그, 프론트엔드 번들에 포함하지 않는다.

## UI/UX

공고 상세 화면의 기존 hero action에 `기업 재무 분석` 버튼을 추가한다. 분석 가능한 경우 앵커로 이동하며, 미매칭이면 버튼을 노출하지 않거나 안내 상태로 렌더링한다.

재무 분석 섹션은 다음 순서다.

1. `AI 기업 전망` 카드: 등급, 다음 사업연도 성장 가능성, 신뢰도, 2~3개 근거 문장, 데이터 기준일, DART 출처 링크.
2. `재무 현황` 카드 그리드: 매출액, 영업이익, 당기순이익, 부채비율/영업현금흐름. 각각 최근 3~5개 사업연도의 막대 또는 선 그래프를 표시한다.
3. `채용 확장성` 카드: 최근 공고 수, 개발직 비중, 주요 직군·기술스택 변화. 재무 전망의 보조 근거임을 구분해 표기한다.
4. 출처·한계: DART 사업연도, 연결/별도 기준, 공시 접수번호 링크, 예측은 투자 조언이 아니라는 고지.

표현 상태는 다음처럼 명확히 나눈다.

- `READY`: DART 고신뢰 매칭, 재무 시계열, 검증된 모델 결과 모두 있음.
- `FINANCIALS_ONLY`: 재무 그래프는 있으나 예측용 이력 또는 모델 결과가 없음.
- `UNMATCHED`: DART 공시법인 고신뢰 매칭 없음. 채용 확장성만 제공.
- `DATA_INSUFFICIENT`: 매칭은 있으나 필요한 재무 이력이 부족함.

## 단계별 인도물

1. DART 연동 기반: 환경설정, 법인 마스터, 매칭 품질 리포트, 재무 수집 검증.
2. 근거 기반 화면: 공고 상세 앵커, 출처 포함 재무 그래프, 미매칭 상태.
3. ML: DART 패널 학습 데이터, 시간 기준 검증, 버전 관리된 예측 결과, AI 전망 카드.
4. 고도화: 누적된 원티드 월간 채용 신호를 검증 후 모델에 추가.

## 성공 기준

- 임의의 화면 값은 모두 저장된 DART 원시 계정, 계산식, 원티드 집계, 또는 저장된 모델 결과로 역추적 가능하다.
- 오매칭 기업에 재무 데이터가 표시되지 않는다.
- 공고 상세에서 사용자 이동 없이 분석 섹션에 접근할 수 있다.
- 모델 결과가 없을 때 그 사실을 명시하며 추정값을 표시하지 않는다.
