# 하이브리드 채용공고 추천 모델

## 판정 원칙

`RULE_BASED_V2`는 공고의 필수 스킬, 자격증, 경력, 학력 조건과 회원 스펙을 비교한다.
이 단계가 **지원 준비도**와 근거 매트릭스의 기준이다. 필수 경력·학력·자격증이 비어 있으면
학습 모델의 관심 점수가 높아도 `바로 지원 가능`으로 승격하지 않는다.

## 학습 모델

AI 서버의 scikit-learn `RandomForestClassifier`가 다음 피처를 사용한다.

- 스킬 요구사항 충족 비율
- 자격증 요구사항 충족 비율
- 경력 및 학력 조건 충족 여부
- 규칙 기반 준비도 점수와 미충족 필수 항목 수
- 회원 희망 직무와 공고 직무 텍스트의 TF-IDF 코사인 유사도

긍정 라벨은 `user_interests`의 공고 찜이다. 부정 라벨은 상세를 본 뒤 찜하지 않은 공고만
사용한다. 아직 보지 않은 공고는 부정으로 취급하지 않는다.

실제 찜이 5건 미만인 초기에는 `RULE_BASED_WEAK_LABEL_V1`로 임시 학습하고, 찜이 5건 이상이면
`BOOKMARK_BEHAVIOR_V1`로 자동 전환한다. 학습 모델이 준비된 경우 최종 정렬 점수는
`규칙 준비도 65% + 관심 확률 35%`로 계산된다.

## 운영

- 매일 한국 시간 06:20에 자동 재학습한다.
- `POST /api/v1/job-matches/model/retrain`은 로그인한 사용자의 수동 재학습 확인용이다.
- AI 서버가 잠시 실패하거나 데이터가 부족하면 규칙 기반 추천이 그대로 유지된다.
